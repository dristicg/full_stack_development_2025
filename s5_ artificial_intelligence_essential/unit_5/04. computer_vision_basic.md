## 1. Computer Vision Basics

### 1.1 Simple Meaning

**Computer Vision** is the branch of AI that lets computers **understand images and video** -- recognizing what is in a picture, where it is, and what is happening.

### 1.2 Everyday Analogy -- The Eye and the Brain

When you look at a cat, your **eyes** only collect light. It is your **brain** that says *"that is a cat."* A computer works the same way: a **camera** is the eye (it only captures light as numbers), and an **AI model** is the brain (it works out what those numbers mean).

### 1.3 How a Computer "Sees" -- An Image Is Just a Grid of Numbers

A computer does not see a picture the way we do. To it, an image is a **grid of tiny squares called pixels**, and every pixel is stored as a **number**.

**Grayscale image:** one number per pixel, from `0` to `255`.

| Pixel Value | Looks Like |
| :-: | :-- |
| `0` | Pure black |
| `128` | Medium gray |
| `255` | Pure white |

**Colour image:** three numbers per pixel -- the amounts of **Red, Green, and Blue (RGB)**, each from `0` to `255`.

| Pixel (R, G, B) | Colour |
| :-: | :-- |
| `(255, 0, 0)` | Red |
| `(0, 255, 0)` | Green |
| `(0, 0, 255)` | Blue |
| `(255, 255, 255)` | White |
| `(0, 0, 0)` | Black |

A normal photo is therefore a very large block of numbers. A `1920 x 1080` colour image has `1920 x 1080 = 2,073,600` pixels, and with three numbers each, that is **`6,220,800` numbers** for a single picture.

### 1.4 The Computer Vision Pipeline

```
FROM A PICTURE TO AN ANSWER

   (1) IMAGE ACQUISITION     A camera captures the picture
              |
              v
   (2) PRE-PROCESSING        Resize, convert to grayscale, reduce noise
              |
              v
   (3) FEATURE EXTRACTION    Find useful patterns: edges, corners, textures
              |
              v
   (4) AI MODEL              Classify, detect, or segment
              |
              v
   (5) OUTPUT                "This is a cat", or a box around it, or an alert
```

| Stage | What Happens | Simple Example |
| :-- | :-- | :-- |
| **1. Image Acquisition** | A camera or sensor captures the image | A phone camera takes a photo |
| **2. Pre-Processing** | The image is tidied so the model gets clean, consistent input | Shrinking a large photo, removing grain |
| **3. Feature Extraction** | Useful patterns are pulled out of the raw pixels | Finding the outline (edges) of an object |
| **4. AI Model** | A trained model uses those features to make a decision | A neural network decides "cat" |
| **5. Output** | The result is delivered | A label, a box, or an alert |

### 1.5 Worked Example -- Finding an Edge with Numbers

An **edge** is a place where the brightness changes sharply, such as the boundary between a dark object and a bright background. Edges are the most basic feature in vision, because they trace the outlines of objects. Here is exactly how a computer finds one.

**The image:** a tiny `5 x 5` grayscale picture -- dark on the left (`10`), bright on the right (`200`).

| | col 0 | col 1 | col 2 | col 3 | col 4 |
| :-: | :-: | :-: | :-: | :-: | :-: |
| **row 0** | 10 | 10 | 200 | 200 | 200 |
| **row 1** | 10 | 10 | 200 | 200 | 200 |
| **row 2** | 10 | 10 | 200 | 200 | 200 |
| **row 3** | 10 | 10 | 200 | 200 | 200 |
| **row 4** | 10 | 10 | 200 | 200 | 200 |

The edge sits between column 1 and column 2, where `10` jumps to `200`.

**The kernel (filter):** a small `3 x 3` grid of numbers that acts as an **edge detector**. Its left column is negative and its right column is positive, so it responds when the right side is brighter than the left:

```
   -1   0   1
   -1   0   1
   -1   0   1
```

**The method:** slide the kernel across the image one step at a time. At each position, **multiply** every pixel under the kernel by the matching kernel number, then **add everything up**.

**Position 1 -- the window over columns 0 to 2:**

```
   Pixels           Kernel          Row by row
   10  10  200      -1  0  1        (10 x -1) + (10 x 0) + (200 x 1) = 190
   10  10  200      -1  0  1        (10 x -1) + (10 x 0) + (200 x 1) = 190
   10  10  200      -1  0  1        (10 x -1) + (10 x 0) + (200 x 1) = 190

                                    Total = 190 + 190 + 190 = 570
```

**All three positions across one row of the image:**

| Window Position | Pixels in Each Row | Calculation per Row | Total (3 rows) |
| :-: | :-: | :-- | :-: |
| **Columns 0-2** | `10, 10, 200` | `-10 + 0 + 200 = 190` | **570** |
| **Columns 1-3** | `10, 200, 200` | `-10 + 0 + 200 = 190` | **570** |
| **Columns 2-4** | `200, 200, 200` | `-200 + 0 + 200 = 0` | **0** |

Repeating this for every row gives the **feature map** (the filter's output):

| | pos 1 | pos 2 | pos 3 |
| :-: | :-: | :-: | :-: |
| **row 1** | **570** | **570** | 0 |
| **row 2** | **570** | **570** | 0 |
| **row 3** | **570** | **570** | 0 |

**How to read it:**
- A **large number (570)** appears wherever the window covers the dark-to-bright boundary. The filter has found the edge.
- **`0`** appears where the window sits entirely on the flat bright area -- no change in brightness, so no edge.
- The **sign** tells the direction of the change. If the picture were reversed (bright on the left, dark on the right), the same filter would give **`-570`**.

### 1.6 Where Neural Networks Come In

In the example above, a human chose the kernel numbers. In a real **Convolutional Neural Network (CNN)**, the network **learns the best kernel numbers by itself** during training -- the same way the perceptron's weights were adjusted in the Introduction to Neural Network note. A deep network stacks many layers of these filters, and each layer builds on the one before:

| Layer Depth | What It Typically Detects |
| :-- | :-- |
| **Early layers** | Simple patterns: edges, corners, color patches |
| **Middle layers** | Shapes and parts: circles, textures, an eye, a wheel |
| **Deep layers** | Whole objects: a face, a car, a cat |

### 1.7 What Computer Vision Can Do -- The Main Tasks

| Task | The Question It Answers | Example |
| :-- | :-- | :-- |
| **Image Classification** | What is in this image? | The photo contains a **cat** |
| **Object Detection** | What is in the image, and **where**? | A box drawn around each car and each pedestrian |
| **Image Segmentation** | Which exact **pixels** belong to which object? | Every pixel of the road is colored differently from the pixels of the sidewalk |
| **Face Recognition** | Whose face is this? | Unlocking a phone |
| **Optical Character Recognition (OCR)** | What text is written here? | Turning a photo of a bill into typed text |

### 1.8 Real-World Uses

| Area | How Computer Vision Helps |
| :-- | :-- |
| **Phones** | Face unlock, photo search, camera effects |
| **Healthcare** | Helps doctors spot abnormalities in X-rays and scans |
| **Self-driving cars** | Detects lanes, other vehicles, pedestrians, and traffic signs |
| **Factories** | Inspects products and spots defects on the production line |
| **Documents** | Reads printed or handwritten text from scanned pages |

### 1.9 Why It Is Hard

| Challenge | Explanation |
| :-- | :-- |
| **Lighting** | The same object looks very different in bright sun, shade, or at night |
| **Viewing Angle** | A chair looks different from the front, side, and top |
| **Partly Hidden Objects** | A person standing behind a pole is only partly visible |
| **Need for Data** | Models usually need thousands of labeled images to learn well |
| **Privacy** | Systems that recognize faces raise serious privacy questions |

## 2. Robotics and Intelligent Automation

### 2.1 Simple Meaning

- **Robotics** is the field of building **machines that can sense their surroundings, make decisions, and carry out physical actions.**
- **Automation** means machines or software doing a task **without a person doing it by hand.**
- **Intelligent Automation** is automation **combined with AI**, so the system can handle messy real-world input (images, text, speech) and unexpected situations -- not just a fixed script.

### 2.2 Everyday Analogy -- The Vending Machine and the Waiter

A **vending machine** is traditional automation: press a button, and it always performs the same fixed steps. A good **waiter** is intelligent automation: he listens to what you say, notices you are in a hurry, suggests something suitable, and adapts when the kitchen runs out of a dish. Both "serve food," but only one **adapts**.

### 2.3 The Sense - Think - Act Loop

Every robot -- from a factory arm to a robot vacuum -- runs the same loop again and again:

![Sense, Think, Act loop](https://res.cloudinary.com/dk16ymotz/image/upload/v1791519021/ad2d4d4f-3b87-4596-84d8-d544a40bac90_ocrcym.jpg)

| Stage | Meaning | Typical Parts |
| :-- | :-- | :-- |
| **Sense** | Collect information about the world | Cameras, **lidar** (laser distance measurement), touch sensors, microphones |
| **Think** | Understand the information, decide, and plan | A processor running AI software (including computer vision from Section 1) |
| **Act** | Carry out the decision physically | **Actuators** -- motors, wheels, robotic arms, grippers |
| **Environment** | The world changes because of the action, and the loop begins again | The room, the shelf, the road |

This is the same **agent and environment** idea from Reinforcement Learning in the Introduction to Machine Learning note: a robot is an agent that acts in the world, and a robot can even **learn** which actions work best through rewards and penalties.

### 2.4 Worked Example -- A Robot Vacuum Cleaner

Many modern robot vacuums run the whole Sense - Think - Act loop:

| Stage | What Happens |
| :-- | :-- |
| **Sense** | A bumper touches a chair leg; a **cliff sensor** notices the edge of a staircase; lidar or a camera measures the distance to the walls; a battery sensor reads `15%` |
| **Think** | The AI builds a **map** of the room, plans a back-and-forth path so no spot is missed, decides to steer away from the stairs, and decides that the battery is low enough to go home and charge |
| **Act** | The wheels turn to steer around the chair, the brush and suction clean the floor, and the robot drives back to its charging dock |
| **Loop** | After every movement, new sensor readings update the map, and the cycle repeats |

Simpler vacuums that just bounce randomly off walls follow fixed rules. The map-building ones are the **intelligent** version: they sense, plan, and adapt.

### 2.5 Traditional Automation vs. Intelligent Automation

| Aspect | **Traditional Automation** | **Intelligent Automation** |
| :-- | :-- | :-- |
| **How It Works** | Follows fixed, pre-written rules | Uses AI to understand its input and adapt |
| **Handles Variation?** | Poorly -- it breaks when something unexpected appears | Much better -- it can cope with differences |
| **Handles Images, Text, Speech?** | No | Yes (using computer vision, NLP, and speech AI) |
| **Example** | A sorting machine that pushes every box heavier than 2 kg into Bin A | A camera system that reads each parcel's label and sends it to the right city's bin, even if the label is tilted or the box is a different size |

### 2.6 More Examples of Intelligent Automation

| Example | How It Works |
| :-- | :-- |
| **Invoice Processing (software)** | A scan of an invoice goes in. **Computer vision (OCR)** turns the image into text, **NLP** finds the vendor, date, and amount, the data is entered into the accounting system automatically, and an unusual amount is flagged for a human to review |
| **Warehouse Robots (physical)** | Cameras locate parcels, the AI plans a path through the aisles, and an arm picks up and moves each item |
| **Quality Inspection (physical)** | A camera inspects each product, and a robot arm removes any that look defective |
| **Customer Support Chatbots (software)** | An NLP model understands the question and answers it, handing over to a person only for hard cases |

### 2.7 Common Types of Robots

| Type | What It Does | Example |
| :-- | :-- | :-- |
| **Industrial Arms** | Fixed in one place, repeat precise movements | Welding or assembling car parts |
| **Mobile Robots** | Move around on wheels or tracks | Warehouse carts, robot vacuums |
| **Drones** | Fly through the air | Aerial photography, crop monitoring |
| **Service Robots** | Help people in everyday settings | Delivery robots, hospital assistants |
| **Humanoid Robots** | Shaped like a human body | Research and demonstration robots |

### 2.8 Challenges

| Challenge | Explanation |
| :-- | :-- |
| **Unpredictable Environments** | A factory floor is controlled; a busy street or a messy home is not |
| **Safety Around People** | A robot must never harm the people working near it |
| **Cost and Maintenance** | Hardware is expensive and wears out |
| **Impact on Jobs** | Automation changes which tasks people do, which raises social and ethical questions |

## 3. AI in IoT and Smart Systems

### 3.1 Simple Meaning

- The **Internet of Things (IoT)** means everyday **physical objects ("things")** that have **sensors and an internet connection**, so they can **collect and share data** -- for example a smart bulb, a fitness band, or a soil-moisture sensor.
- On its own, IoT only **gathers** data. **AI** is what **makes sense of that data and decides what to do**. IoT with AI is often called **AIoT** (Artificial Intelligence of Things).
- A **Smart System** is a system that **senses, analyses, decides, acts, and improves** with experience.

### 3.2 Everyday Analogy -- Senses, Nerves, and Brain

Think of the human body. The **eyes, ears, and skin** are the **sensors**. The **nerves** carry signals to the brain -- that is the **internet connection**. The **brain** interprets the signals and decides what to do -- that is the **AI**. The muscles then carry out the decision -- the **actuators**. A smart system is built exactly like this.

### 3.3 How an AI-Powered IoT System Is Built

```
THE LAYERS OF A SMART SYSTEM

   [ 1. DEVICES AND SENSORS ]   Collect raw data from the real world
              |
              v
   [ 2. CONNECTIVITY ]          Carries the data (Wi-Fi, Bluetooth, 5G, ...)
              |
              v
   [ 3. DATA PROCESSING ]       Done on the device (edge) or on a server (cloud)
              |
              v
   [ 4. AI ANALYSIS ]           Finds patterns, predicts, and decides
              |
              v
   [ 5. ACTION ]                Controls a device or alerts a person
              |
              +-----> New sensor readings arrive and the loop continues
```

| Layer | Role | Examples |
| :-- | :-- | :-- |
| **1. Devices and Sensors** | Measure the physical world | Temperature, motion, soil moisture, heart rate, camera |
| **2. Connectivity** | Move the data to where it is processed | Wi-Fi, Bluetooth, mobile networks (4G/5G); a lightweight messaging protocol called **MQTT** is commonly used |
| **3. Data Processing** | Store and prepare the data | On a small chip in the device, or on cloud servers |
| **4. AI Analysis** | Learn from the data and make decisions | A model that predicts a machine failure |
| **5. Action** | Turn the decision into something real | Switch a valve, change a setting, send an alert to a phone |

### 3.4 Edge AI vs. Cloud AI -- Where Does the AI Run?

The AI "brain" can sit in two different places:

| Aspect | **Edge AI** (on the device) | **Cloud AI** (on remote servers) |
| :-- | :-- | :-- |
| **Where It Runs** | On the sensor, camera, or phone itself | On powerful servers reached over the internet |
| **Speed** | Very fast, because no data has to travel | Slower, depends on the network |
| **Internet Needed?** | No -- works even offline | Yes |
| **Privacy** | Data can stay on the device | Data is sent to a server |
| **Computing Power** | Limited by the small device | Very large |
| **Example** | A phone unlocking itself with your face | Analysing the traffic data of a whole city |

Real systems often **combine both**: quick decisions are made at the edge, while heavy analysis and model training happen in the cloud.

### 3.5 Worked Example -- A Smart Air Conditioner

*(The sensor values below are made-up illustrative numbers.)*

| Stage | What Happens |
| :-- | :-- |
| **Sense** | Temperature sensor reads `31 °C`; the motion sensor detects that someone just entered the room; the clock says `7:00 PM` on a weekday |
| **Connect** | The readings travel over Wi-Fi to the AC's controller |
| **Think (AI)** | A model trained on past usage has learned that on weekday evenings this household sets the AC to about `24 °C` |
| **Act** | The AC sets itself to `24 °C` and starts cooling, with no button pressed |
| **Learn** | If the user changes the setting to `23 °C`, the system records it and adjusts its prediction for next time |

**A plain connected AC** only follows commands -- you press a button, or an app sends a "switch on" instruction. **A smart AC** decides for itself, using what it has learned. That difference is exactly what AI adds to IoT.

### 3.6 More Smart Systems

| Smart System | Sensors Used | What the AI Does | Action Taken |
| :-- | :-- | :-- | :-- |
| **Smart Agriculture** | Soil-moisture sensor, weather data | Combines the soil reading with the rain forecast to decide whether watering is needed | Starts or skips irrigation |
| **Smart City Traffic** | Cameras, vehicle counters | Estimates how heavy traffic is on each road | Adjusts traffic-signal timing |
| **Predictive Maintenance** | Vibration and temperature sensors on a machine | Spots the pattern that usually appears before a breakdown | Sends a repair alert **before** the machine fails |
| **Wearable Health Band** | Heart-rate sensor, motion sensor | Detects an unusual heartbeat pattern | Alerts the wearer, who can then contact a doctor |
| **Smart Energy Meter** | Electricity-usage meter | Spots abnormal consumption | Notifies the user of a possible fault or waste |

### 3.7 Challenges

| Challenge | Explanation |
| :-- | :-- |
| **Security** | Every connected device is a possible entry point for hackers |
| **Privacy** | Sensors in homes and on bodies collect very personal data |
| **Connectivity** | Devices in remote areas may have a weak or unreliable connection |
| **Limited Power** | Small battery-powered devices cannot run large AI models |
| **Compatibility** | Devices from different makers do not always work together |

## 4. Putting All Three Together -- A Smart Factory

A modern factory uses **all three** ideas at once. Follow one product along the production line:

```
ONE PRODUCT'S JOURNEY THROUGH A SMART FACTORY

   A product moves along the conveyor belt
              |
              v
   [ COMPUTER VISION ]   A camera photographs it, and the AI model decides:
                          good product, or cracked product?
              |  (cracked)
              v
   [ IoT ]               The result is sent over the network to the robot's
                          controller, and a sensor counts the defect
              |
              v
   [ ROBOTICS ]          The robot arm picks the cracked product off the belt
              |
              v
   [ IoT ]               The defect count updates on the manager's dashboard
```

In the same factory, **IoT sensors on the machines** measure vibration and temperature, and an AI model uses them to warn when a machine is likely to fail -- the predictive maintenance example from Section 3.6.

### 4.1 The Three Fields Compared

| Aspect | **Computer Vision** | **Robotics and Intelligent Automation** | **AI in IoT and Smart Systems** |
| :-- | :-- | :-- | :-- |
| **Role** | The **eyes** | The **hands** | The **senses and nerves** |
| **Main Input** | Images and video | Sensor data about the surroundings | Data from many connected sensors |
| **What the AI Does** | Understands what the image shows | Decides and plans physical actions | Finds patterns and makes decisions from sensor data |
| **Main Output** | A label, a box, or a mask | Physical movement | An automatic action or an alert |
| **Example** | Spotting a cracked product | A robot arm removing it | A dashboard counting defects and warning about machine failure |

All three follow the same pattern: **sense, think, act, and improve.**

## 5. Summary

| Concept | One-Line Summary |
| :-- | :-- |
| **Computer Vision** | The branch of AI that lets computers understand images and video |
| **Pixel** | A single number (grayscale) or three numbers (RGB colour) that make up one dot of an image |
| **Image as Numbers** | A computer sees a picture only as a grid of numbers; a `1920 x 1080` colour image is `6,220,800` numbers |
| **Edge Detection** | Sliding a small kernel over the image, multiplying and adding, to find sharp changes in brightness |
| **Kernel / Filter** | A small grid of numbers that picks out one pattern; in a CNN these numbers are learned automatically |
| **Vision Tasks** | Classification (what), detection (what and where), segmentation (which pixels), face recognition, OCR |
| **Robotics** | Machines that sense their surroundings, decide, and act physically |
| **Intelligent Automation** | Automation plus AI, so it can adapt to messy input and unexpected situations |
| **Sense - Think - Act Loop** | The repeating cycle every robot follows: collect data, decide, act, then sense the changed world |
| **Traditional vs. Intelligent Automation** | Fixed rules versus AI that understands and adapts |
| **IoT** | Everyday objects with sensors and an internet connection that collect and share data |
| **AIoT / Smart System** | IoT combined with AI, so the system senses, analyses, decides, acts, and improves |
| **IoT System Layers** | Devices and sensors, connectivity, data processing, AI analysis, action |
| **Edge vs. Cloud AI** | Edge AI runs on the device (fast, private, limited power); cloud AI runs on servers (powerful, needs internet) |
| **The Common Thread** | Vision sees, robotics acts, IoT senses and connects -- and together they sense, think, act, and improve |
