# K-Nearest Neighbours (KNN) Algorithm
## 1. What is KNN?

### 1.1 Definition

| Item | Details |
| :-- | :-- |
| **Full Form** | **K-Nearest Neighbours** |
| **Type** | A **supervised machine learning** algorithm |
| **Used For** | **Classification** (predicting a **category**) and **Regression** (predicting a **number**) |
| **Core Idea** | A new data point is predicted using the **K most similar (closest) data points** from the training data |
| **Simple Analogy** | *"Tell me who your neighbours are, and I will tell you who you are."* |

### 1.2 Key Characteristics

| Characteristic | Meaning |
| :-- | :-- |
| **Lazy Learner** | KNN does **no training**. It simply **stores the data** and does all the work **at prediction time** |
| **Instance-Based** | Predictions are made by comparing the new point **directly with stored examples** |
| **Non-Parametric** | It makes **no assumption** about the shape or distribution of the data |
| **Distance-Based** | "Closeness" is measured using a **distance formula**, most commonly **Euclidean distance** |

### 1.3 Basic Terminology Used in KNN

| Term | Meaning |
| :-- | :-- |
| **Query Point** | The **new data point** whose class or value we want to predict |
| **K** | The **number of nearest neighbours** considered for the prediction |
| **Neighbour** | A **training data point** that is close to the query point |
| **Distance Metric** | The formula used to measure **how far apart** two points are |
| **Majority Voting** | **Classification rule**: the class that appears **most often** among the K neighbours wins |
| **Averaging** | **Regression rule**: the prediction is the **mean** of the K neighbours' values |

***

## 2. Euclidean Distance Formula

### 2.1 The Formula

**Euclidean distance** is the **straight-line distance** between two points.

For **two features**:

```
d(P, Q) = √[ (x₁ − x₂)² + (y₁ − y₂)² ]
```

For **n features** (general form):

```
d(P, Q) = √[ (p₁ − q₁)² + (p₂ − q₂)² + ... + (pₙ − qₙ)² ]
```

| Symbol | Meaning |
| :-- | :-- |
| **P** | The **query point** (new data) |
| **Q** | A **training data point** |
| **pᵢ, qᵢ** | The value of the **i-th feature** of P and Q |
| **n** | The **number of features** |

### 2.2 Quick Example

| Item | Details |
| :-- | :-- |
| **Points** | P = (**2, 3**) and Q = (**5, 7**) |
| **Step 1** | Differences: (2 − 5) = **−3** and (3 − 7) = **−4** |
| **Step 2** | Squares: (−3)² = **9** and (−4)² = **16** |
| **Step 3** | Sum = 9 + 16 = **25** |
| **Step 4** | d = √25 = **5** |

**Smaller distance = more similar.**

## 3. How KNN Works (Step by Step)

### 3.1 The Algorithm

```
        ┌──────────────────────────────────────┐
        │ 1. Choose the value of K             │
        └───────────────────┬──────────────────┘
                            ▼
        ┌──────────────────────────────────────┐
        │ 2. Take the new (query) data point   │
        └───────────────────┬──────────────────┘
                            ▼
        ┌──────────────────────────────────────┐
        │ 3. Calculate the Euclidean distance  │
        │    to EVERY training data point      │
        └───────────────────┬──────────────────┘
                            ▼
        ┌──────────────────────────────────────┐
        │ 4. Sort the distances (smallest      │
        │    to largest)                       │
        └───────────────────┬──────────────────┘
                            ▼
        ┌──────────────────────────────────────┐
        │ 5. Select the K nearest neighbours   │
        └───────────────────┬──────────────────┘
                   ┌────────┴─────────┐
            Classification        Regression
                   ▼                  ▼
        ╭────────────────────╮ ╭────────────────────╮
        │ 6a. MAJORITY VOTE  │ │ 6b. AVERAGE of the │
        │ of the K labels    │ │ K values           │
        ╰────────────────────╯ ╰────────────────────╯
```

### 3.2 Step Summary

| Step | What Happens |
| :-- | :-- |
| **(1)** | Choose **K** (for example, K = 3) |
| **(2)** | Take the **new data point** to be predicted |
| **(3)** | Compute the **Euclidean distance** from the new point to **all training points** |
| **(4)** | **Sort** the training points by distance, **smallest first** |
| **(5)** | Pick the **top K** points. These are the **nearest neighbours** |
| **(6)** | **Classification** → take the **majority class**. **Regression** → take the **average value** |

## 4. KNN for Classification: Movie Genre Prediction

### 4.1 Problem Statement

| Item | Details |
| :-- | :-- |
| **Goal** | Predict the **genre** of a new movie: **Action**, **Comedy**, **Drama** or **Thriller** |
| **Type** | **Classification** (the output is a **category**) |
| **Features** | Each movie is scored from **1 to 10** on four features: **Action**, **Humor**, **Suspense**, **Emotion** |
| **Value of K** | **K = 3** |
| **Distance** | **Euclidean distance** |

### 4.2 Training Data (12 Known Movies)

| Movie | Action | Humor | Suspense | Emotion | Genre |
| :-- | :-: | :-: | :-: | :-: | :-- |
| Movie 1 | 9 | 2 | 5 | 2 | **Action** |
| Movie 2 | 8 | 3 | 4 | 3 | **Action** |
| Movie 3 | 9 | 1 | 6 | 1 | **Action** |
| Movie 4 | 2 | 9 | 1 | 4 | **Comedy** |
| Movie 5 | 3 | 8 | 2 | 3 | **Comedy** |
| Movie 6 | 1 | 9 | 2 | 5 | **Comedy** |
| Movie 7 | 1 | 2 | 2 | 9 | **Drama** |
| Movie 8 | 2 | 3 | 3 | 8 | **Drama** |
| Movie 9 | 2 | 1 | 2 | 9 | **Drama** |
| Movie 10 | 4 | 1 | 9 | 3 | **Thriller** |
| Movie 11 | 5 | 2 | 8 | 2 | **Thriller** |
| Movie 12 | 3 | 2 | 9 | 4 | **Thriller** |

### 4.3 New Movie (Query Point)

| Movie | Action | Humor | Suspense | Emotion | Genre |
| :-- | :-: | :-: | :-: | :-: | :-- |
| **New Movie** | **4** | **2** | **8** | **3** | **?** |

### 4.4 Step 1: Calculate the Euclidean Distance to Every Movie

**Worked example** (New Movie vs Movie 10):

```
d = √[ (4−4)² + (2−1)² + (8−9)² + (3−3)² ]
  = √[ 0 + 1 + 1 + 0 ]
  = √2
  ≈ 1.41
```

The same calculation for **all 12 movies**:

| Movie | Genre | (ΔAction)² | (ΔHumor)² | (ΔSuspense)² | (ΔEmotion)² | Sum | Distance |
| :-- | :-- | :-: | :-: | :-: | :-: | :-: | :-: |
| Movie 1 | Action | 25 | 0 | 9 | 1 | 35 | **5.92** |
| Movie 2 | Action | 16 | 1 | 16 | 0 | 33 | **5.74** |
| Movie 3 | Action | 25 | 1 | 4 | 4 | 34 | **5.83** |
| Movie 4 | Comedy | 4 | 49 | 49 | 1 | 103 | **10.15** |
| Movie 5 | Comedy | 1 | 36 | 36 | 0 | 73 | **8.54** |
| Movie 6 | Comedy | 9 | 49 | 36 | 4 | 98 | **9.90** |
| Movie 7 | Drama | 9 | 0 | 36 | 36 | 81 | **9.00** |
| Movie 8 | Drama | 4 | 1 | 25 | 25 | 55 | **7.42** |
| Movie 9 | Drama | 4 | 1 | 36 | 36 | 77 | **8.77** |
| Movie 10 | Thriller | 0 | 1 | 1 | 0 | 2 | **1.41** |
| Movie 11 | Thriller | 1 | 0 | 0 | 1 | 2 | **1.41** |
| Movie 12 | Thriller | 1 | 0 | 1 | 1 | 3 | **1.73** |

### 4.5 Step 2: Sort by Distance (Smallest First)

| Rank | Movie | Genre | Distance |
| :-: | :-- | :-- | :-: |
| **1** | Movie 10 | **Thriller** | **1.41** |
| **2** | Movie 11 | **Thriller** | **1.41** |
| **3** | Movie 12 | **Thriller** | **1.73** |
| 4 | Movie 2 | Action | 5.74 |
| 5 | Movie 3 | Action | 5.83 |
| 6 | Movie 1 | Action | 5.92 |
| 7 | Movie 8 | Drama | 7.42 |
| 8 | Movie 5 | Comedy | 8.54 |
| 9 | Movie 9 | Drama | 8.77 |
| 10 | Movie 7 | Drama | 9.00 |
| 11 | Movie 6 | Comedy | 9.90 |
| 12 | Movie 4 | Comedy | 10.15 |

### 4.6 Step 3: Select K = 3 Nearest Neighbours and Vote

```
                  ╭──────────────────╮
                  │    New Movie     │
                  │  (4, 2, 8, 3)    │
                  ╰────────┬─────────╯
        ┌──────────────────┼──────────────────┐
        ▼                  ▼                  ▼
┌───────────────┐  ┌───────────────┐  ┌───────────────┐
│  Movie 10     │  │  Movie 11     │  │  Movie 12     │
│  d = 1.41     │  │  d = 1.41     │  │  d = 1.73     │
│  THRILLER     │  │  THRILLER     │  │  THRILLER     │
└───────────────┘  └───────────────┘  └───────────────┘
```

| Genre | Votes among the 3 Neighbours |
| :-- | :-: |
| **Thriller** | **3** |
| Action | 0 |
| Comedy | 0 |
| Drama | 0 |

**Prediction: the New Movie is a THRILLER** (it received **3 out of 3 votes**).

### 4.7 Effect of Changing K

| Value of K | Neighbours Used | Votes | Prediction |
| :-: | :-- | :-- | :-- |
| **K = 1** | Movie 10 | Thriller = 1 | **Thriller** |
| **K = 3** | Movies 10, 11, 12 | Thriller = 3 | **Thriller** |
| **K = 5** | Movies 10, 11, 12, 2, 3 | Thriller = 3, Action = 2 | **Thriller** |
| **K = 9** | First 9 movies in the sorted list | Thriller = 3, Action = 3, Drama = 2, Comedy = 1 | **Tie (Thriller vs Action)** |

**Lesson:** A **very large K** pulls in **far-away, unrelated movies** and can **blur or break the result**. A **small, well-chosen K** keeps the decision **local**.

## 5. KNN for Regression: House Price Prediction

### 5.1 Problem Statement

| Item | Details |
| :-- | :-- |
| **Goal** | Predict the **price of a house** (a **number**) |
| **Type** | **Regression** (the output is a **continuous value**) |
| **Features** | **Area** (in 100 sq ft), **Bedrooms**, **Age** (in years) |
| **Target** | **Price** (in ₹ Lakhs) |
| **Value of K** | **K = 3** |
| **Distance** | **Euclidean distance** (same as in classification) |

### 5.2 Training Data (8 Known Houses)

| House | Area (100 sq ft) | Bedrooms | Age (years) | Price (₹ Lakhs) |
| :-- | :-: | :-: | :-: | :-: |
| House 1 | 12 | 2 | 5 | **45** |
| House 2 | 15 | 3 | 3 | **60** |
| House 3 | 18 | 3 | 8 | **62** |
| House 4 | 20 | 4 | 2 | **85** |
| House 5 | 25 | 4 | 4 | **105** |
| House 6 | 10 | 1 | 15 | **30** |
| House 7 | 22 | 4 | 6 | **88** |
| House 8 | 30 | 5 | 1 | **130** |

### 5.3 New House (Query Point)

| House | Area (100 sq ft) | Bedrooms | Age (years) | Price (₹ Lakhs) |
| :-- | :-: | :-: | :-: | :-: |
| **New House** | **16** | **3** | **4** | **?** |

### 5.4 Step 1: Calculate the Euclidean Distance to Every House

**Worked example** (New House vs House 2):

```
d = √[ (16−15)² + (3−3)² + (4−3)² ]
  = √[ 1 + 0 + 1 ]
  = √2
  ≈ 1.41
```

The same calculation for **all 8 houses**:

| House | (ΔArea)² | (ΔBedrooms)² | (ΔAge)² | Sum | Distance | Price (₹ Lakhs) |
| :-- | :-: | :-: | :-: | :-: | :-: | :-: |
| House 1 | 16 | 1 | 1 | 18 | **4.24** | 45 |
| House 2 | 1 | 0 | 1 | 2 | **1.41** | 60 |
| House 3 | 4 | 0 | 16 | 20 | **4.47** | 62 |
| House 4 | 16 | 1 | 4 | 21 | **4.58** | 85 |
| House 5 | 81 | 1 | 0 | 82 | **9.06** | 105 |
| House 6 | 36 | 4 | 121 | 161 | **12.69** | 30 |
| House 7 | 36 | 1 | 4 | 41 | **6.40** | 88 |
| House 8 | 196 | 4 | 9 | 209 | **14.46** | 130 |

### 5.5 Step 2: Sort by Distance (Smallest First)

| Rank | House | Distance | Price (₹ Lakhs) |
| :-: | :-- | :-: | :-: |
| **1** | House 2 | **1.41** | **60** |
| **2** | House 1 | **4.24** | **45** |
| **3** | House 3 | **4.47** | **62** |
| 4 | House 4 | 4.58 | 85 |
| 5 | House 7 | 6.40 | 88 |
| 6 | House 5 | 9.06 | 105 |
| 7 | House 6 | 12.69 | 30 |
| 8 | House 8 | 14.46 | 130 |

### 5.6 Step 3: Select K = 3 Nearest Neighbours and Average

```
                  ╭──────────────────╮
                  │    New House     │
                  │    (16, 3, 4)    │
                  ╰────────┬─────────╯
        ┌──────────────────┼──────────────────┐
        ▼                  ▼                  ▼
┌───────────────┐  ┌───────────────┐  ┌───────────────┐
│   House 2     │  │   House 1     │  │   House 3     │
│  d = 1.41     │  │  d = 4.24     │  │  d = 4.47     │
│  ₹ 60 Lakhs   │  │  ₹ 45 Lakhs   │  │  ₹ 62 Lakhs   │
└───────────────┘  └───────────────┘  └───────────────┘
```

```
Predicted Price = (60 + 45 + 62) / 3
                = 167 / 3
                ≈ 55.67 Lakhs
```

**Prediction: the New House is worth about ₹ 55.67 Lakhs.**

### 5.7 Effect of Changing K

| Value of K | Neighbours Used | Calculation | Predicted Price |
| :-: | :-- | :-- | :-: |
| **K = 1** | House 2 | 60 | **₹ 60.00 Lakhs** |
| **K = 3** | Houses 2, 1, 3 | (60 + 45 + 62) / 3 | **₹ 55.67 Lakhs** |
| **K = 4** | Houses 2, 1, 3, 4 | (60 + 45 + 62 + 85) / 4 | **₹ 63.00 Lakhs** |

**Lesson:** The prediction **changes with K**. A **small K** follows the **nearest example closely** (and is sensitive to noise), while a **larger K** gives a **smoother average** but can be pulled toward **less similar** houses.

### 5.8 Classification vs Regression in KNN

| Aspect | Classification (Movie Genre) | Regression (House Price) |
| :-- | :-- | :-- |
| **Output** | A **category** (Action, Comedy, Drama, Thriller) | A **number** (price in ₹ Lakhs) |
| **Distance Formula** | **Euclidean** | **Euclidean** (**identical**) |
| **Steps 1 to 5** | Compute distances, sort, pick K | Compute distances, sort, pick K (**identical**) |
| **Final Step** | **Majority vote** of the K labels | **Average** of the K values |
| **Example Result** | **Thriller** | **₹ 55.67 Lakhs** |

**Only the last step differs.** Everything before it is exactly the same.

## 6. Limitations of KNN

| # | Limitation | Explanation | Impact / Common Fix |
| :-: | :-- | :-- | :-- |
| **1** | **Slow Predictions** | KNN is a **lazy learner**. For every query it must compute the **distance to all training points** | Becomes **very slow on large datasets**. Use **KD-Trees, Ball Trees** or **approximate search** |
| **2** | **High Memory Usage** | The **entire training dataset** must be **stored** | Not suitable for **very large data** or **small devices** |
| **3** | **Sensitive to Feature Scale** | Features with **large ranges** (for example, Area) **dominate** the distance over features with small ranges (for example, Bedrooms) | Always apply **normalization or standardization** (for example, **Min-Max scaling**) first |
| **4** | **Curse of Dimensionality** | In **high-dimensional data**, all points become **almost equally far apart**, so "nearest" loses meaning | Use **feature selection** or **dimensionality reduction** (for example, **PCA**) |
| **5** | **Sensitive to Irrelevant Features** | Every feature counts **equally** in the distance, so **useless features add noise** | Remove **irrelevant features** or apply **feature weighting** |
| **6** | **Choosing the Right K** | **Small K** → **noisy, overfits**. **Large K** → **too smooth, underfits** | Try several values and use **cross-validation**. For classification, prefer an **odd K** to avoid ties |
| **7** | **Sensitive to Outliers and Noise** | A few **bad or extreme points** near the query can **mislead** the result, especially with a small K | **Clean the data**, use a **larger K** or **distance-weighted voting** |
| **8** | **Imbalanced Classes** | The **majority class** dominates the vote, so **minority classes get under-predicted** | Use **distance-weighted voting**, **resampling** or **class weights** |
| **9** | **Cannot Handle Missing Values** | A distance cannot be computed when a **feature value is missing** | **Impute** missing values before using KNN |
| **10** | **No Learned Model** | KNN builds **no explicit model or rules**, so it gives **no general insight** into the data | Use a **model-based algorithm** (for example, Decision Tree) if understanding the data matters |

***

## 7. Summary

| Topic | Key Idea |
| :-- | :-- |
| **What is KNN** | A **supervised, lazy, distance-based** algorithm that predicts using the **K nearest training points** |
| **Distance Formula** | **Euclidean distance**: d = √[Σ (pᵢ − qᵢ)²] |
| **How It Works** | **Choose K → compute distances → sort → pick K nearest → vote or average** |
| **Classification Example** | **Movie genre**: the 3 nearest movies were all **Thrillers**, so the new movie is a **Thriller** |
| **Regression Example** | **House price**: the average of the 3 nearest houses gave **≈ ₹ 55.67 Lakhs** |
| **Classification vs Regression** | Same distance and same neighbours. Only the **final step** differs (**vote** vs **average**) |
| **Limitations** | **Slow**, **memory heavy**, **needs scaling**, **hurt by high dimensions**, **sensitive to K, noise and imbalance** |
