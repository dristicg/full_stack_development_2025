# Regression and Classification
## 1. Quick Recap: Supervised Learning

### 1.1 Simple Meaning

**Supervised Learning** is the branch of Machine Learning where the algorithm learns from a **labeled dataset**, meaning every training example contains **the inputs (features)** and **the correct answer (target)**.

The model studies these examples, learns the **relationship between inputs and answers**, and then uses that relationship to **predict answers for new, unseen data**.

### 1.2 Key Terms Used in This Note

| Term | Symbol | Meaning |
| :-- | :-- | :-- |
| **Features** | `X` | The **input information** given to the model (e.g., size of a house, words in an email) |
| **Target** | `y` | The **correct answer** the model must learn to predict (e.g., house price, spam or not spam) |
| **Training Data** | — | Labeled examples used to **teach** the model |
| **Testing Data** | — | Separate, **unseen** examples used to **check** how well the model learned |

***

## 2. Types of Supervised Learning

Supervised Learning involves **two primary types of tasks**: **Regression** and **Classification**.

The only real difference between them is **what kind of answer (target) the model predicts**.

```
              SUPERVISED LEARNING
                           │
            ┌──────────────┴──────────────┐
            ▼                             ▼
       REGRESSION                    CLASSIFICATION
   (continuous values)             (discrete labels)
```

| Task | What It Predicts | Type of Target | Examples |
| :-- | :-- | :-- | :-- |
| **Regression** | **Continuous values** (any number within a range) | Numerical | Predicting **house prices** based on size and location, estimating the **temperature for the next day**, forecasting **sales revenue** |
| **Classification** | **Discrete labels** (a fixed set of categories) | Categorical | **Email spam detection** (Spam or Not Spam), **image recognition** (Cat, Dog, or Other), **medical diagnosis** (Disease A, Disease B, No Disease) |

> **The Quick Test:** Ask *"Is my answer a number on a scale, or a category from a list?"*

| If the answer is... | Then use... |
| :-- | :-- |
| A **number** that can be anything in a range (`25.4°C`, `₹52,00,000`) | **Regression** |
| A **category / label** from a fixed list (`Spam`, `Cat`, `Disease A`) | **Classification** |

***

## 3. Regression

### 3.1 Simple Meaning

**Regression** is used when the **target variable is continuous**, meaning it can take **any numerical value within a range**.

The model does not choose from a list. It **estimates a number**.

> **The Analogy: Volume Knob**

Think of the volume knob on a speaker. It does not have only "Low" and "High". It can be set to **any position in between**: 12%, 47.5%, 80%. Regression predicts values on this kind of **smooth, continuous scale**.

### 3.2 Example Use Case: Predicting House Prices

| Stage | What Happens |
| :-- | :-- |
| **The Data** | A dataset of past house sales, where each house has its **size (sq ft)**, **number of bedrooms**, and **location**, along with the **price it sold for** |
| **The Learning** | The model discovers the relationship, for example that **bigger houses and better locations usually cost more** |
| **The Outcome** | When a new house is listed, the model uses the learned relationship to **estimate its price** |

| Part | Role | Value in This Example |
| :-- | :-- | :-- |
| **Features (X)** | Inputs | Size (sq ft), number of bedrooms, location |
| **Target (y)** | Output | House price |

```
 FEATURES (X)                                          TARGET (y)
 Size, Bedrooms, Location  ──►  REGRESSION MODEL  ──►  House Price
                                                    (a continuous number)
```

### 3.3 How Regression Works

```
(1) TRAIN      Model is trained on a dataset with features (X)
                and a continuous target variable (y)
                          │
                          ▼
(2) LEARN      It learns the relationship between the
                inputs and the output
                          │
                          ▼
(3) PREDICT    During prediction, the model uses the learned
                relationship to estimate the target value
                for new inputs
```

| Step | Stage | Meaning |
| :-- | :-- | :-- |
| **(1)** | **Train** | The model is trained on a dataset with **features (`X`)** and a **continuous target variable (`y`)** |
| **(2)** | **Learn** | It learns the **relationship between the inputs and the output** |
| **(3)** | **Predict** | During prediction, the model uses the **learned relationship** to **estimate the target value for new inputs** |

### 3.4 Common Regression Algorithms

| Algorithm | Short Description |
| :-- | :-- |
| **Linear Regression** | Fits a **straight line** through the data to show how the target changes with the features |
| **Polynomial Regression** | Fits a **curved line**, useful when the relationship is not a straight line |
| **Decision Trees (for regression)** | Splits the data using a series of questions and predicts a **number** at each end point |
| **Random Forests (for regression)** | Combines **many decision trees** and averages their predictions for better accuracy |
| **Support Vector Regression (SVR)** | Finds a line or curve that fits the data within an **acceptable margin of error** |

### 3.5 How Regression Is Measured

Because the answer is a number, we measure **how far the prediction is from the real value**.

| Metric | Meaning |
| :-- | :-- |
| **MAE** (Mean Absolute Error) | The **average size of the mistakes**. Lower is better |
| **MSE / RMSE** (Mean Squared Error / Root MSE) | Like MAE, but **large mistakes are punished more**. Lower is better |
| **R² Score** | How much of the change in the target the model **explains**. Closer to `1` is better |

## 4. Classification

### 4.1 Simple Meaning

**Classification** is used when the **target variable is categorical**, meaning it represents **discrete classes or labels**.

The model does not estimate a number. It **chooses a category**.

> **The Analogy: Sorting Mail into Labeled Boxes**

A post office worker has three boxes labeled **"Local"**, **"National"**, and **"International"**. Each letter that arrives must go into **exactly one box**. There is no such thing as "half Local, half National". Classification works the same way by putting each new item into the **most suitable labeled box**.

### 4.2 Example Use Case: Email Spam Detection

| Stage | What Happens |
| :-- | :-- |
| **The Data** | Thousands of emails already marked by humans as **"Spam"** or **"Not Spam"** |
| **The Learning** | The model learns which **words and phrases** (like *"win free money"*) appear mostly in spam |
| **The Outcome** | When a new email arrives, the model **assigns the most likely class** and moves it to the correct folder |

| Part | Role | Value in This Example |
| :-- | :-- | :-- |
| **Features (X)** | Inputs | Words in the email, frequency of certain phrases |
| **Target (y)** | Output | Spam or Not Spam |

```
 FEATURES (X)                                             TARGET (y)
 Words in email,              ──►  CLASSIFICATION  ──►  Spam  /  Not Spam
 phrase frequency                      MODEL            (a discrete label)
```

### 4.3 How Classification Works

```
(1) TRAIN      Model is trained on a dataset with features (X)
                and categorical labels (y)
                          │
                          ▼
(2) LEARN      It learns the decision boundaries between classes
                          │
                          ▼
(3) PREDICT    During prediction, the model assigns the most
                likely class to new inputs
```

| Step | Stage | Meaning |
| :-- | :-- | :-- |
| **(1)** | **Train** | The model is trained on a dataset with **features (`X`)** and **categorical labels (`y`)** |
| **(2)** | **Learn** | It learns the **decision boundaries between classes**, the "dividing lines" that separate one class from another |
| **(3)** | **Predict** | During prediction, the model **assigns the most likely class** to new inputs |

### 4.4 Types of Classification

| Type | Meaning | Example |
| :-- | :-- | :-- |
| **Binary Classification** | Only **two** possible classes | Spam / Not Spam |
| **Multi-Class Classification** | **Three or more** possible classes, and each item gets one | Cat / Dog / Other |

### 4.5 Common Classification Algorithms

| Algorithm | Short Description |
| :-- | :-- |
| **Logistic Regression** | Calculates the **probability** of each class. Despite its name, it is a **classification** algorithm |
| **Decision Trees (for classification)** | Splits the data using a series of yes/no questions until it reaches a **class label** |
| **Random Forests (for classification)** | Combines **many decision trees** and picks the class most trees vote for |
| **Support Vector Machines (SVM)** | Finds the **best dividing line (boundary)** with the widest gap between classes |
| **Neural Networks** | Layers of connected nodes that learn **complex patterns**, such as those in images and speech |

### 4.6 How Classification Is Measured

| Metric | Meaning |
| :-- | :-- |
| **Accuracy** | Out of all predictions, the **percentage that were correct** |
| **Precision** | Out of everything predicted as a class, how much was **truly** that class |
| **Recall** | Out of everything that truly belongs to a class, how much the model **found** |
| **F1 Score** | A single score that **balances Precision and Recall** |

## 5. Direct Comparison Overview

| Feature | **Regression** | **Classification** |
| :-- | :-- | :-- |
| **Target Variable** | **Continuous** (any number in a range) | **Categorical** (discrete classes or labels) |
| **Goal** | **Estimate a number** | **Assign a category** |
| **What the Model Learns** | The **relationship between inputs and the output value** | The **decision boundaries between classes** |
| **Output Example** | `₹52,00,000`, `31.5°C`, `1,20,000 units` | `Spam`, `Cat`, `Disease A` |
| **Example Tasks** | House prices, next-day temperature, sales forecasting | Spam detection, image recognition, medical diagnosis |
| **Common Algorithms** | Linear Regression, Polynomial Regression, Decision Trees, Random Forests, SVR | Logistic Regression, Decision Trees, Random Forests, SVM, Neural Networks |
| **Typical Metrics** | MAE, RMSE, R² | Accuracy, Precision, Recall, F1 |

> **Note:** Decision Trees and Random Forests appear in **both** columns because they can be adapted for either task. The difference is only the type of target they predict.

## 6. How ML Models Work: Training and Testing

### 6.1 Simple Meaning

Every supervised model (regression or classification) goes through **two phases**:

| Phase | Data Used | Purpose |
| :-- | :-- | :-- |
| **Training Phase** | **Training Data** = **Labeled Data** + **Labels** | The model **learns** patterns from examples where the answers are known |
| **Testing Phase** | **Test Data** | The model makes **predictions on new items** it has never seen before |

### 6.2 Example: Learning to Identify Shapes

In this example the model is taught to recognize shapes.

| Item | Details |
| :-- | :-- |
| **Labeled Data** | A collection of shapes: **3 hexagons, 3 squares, and 3 triangles** |
| **Labels** | The correct names for the shapes: **Hexagon, Square, Triangle** |
| **Model Training** | The model receives the labeled data **together with** the labels and learns what each shape looks like |
| **Test Data** | New shapes the model has not seen before: **a Square and a Triangle** |
| **Prediction** | The trained model looks at the test data and **predicts** the label for each shape |
| **Output** | **Square** and **Triangle** |

```

 │                                                     │
 │ ┌───────────────────────┐      ┌─────────────────┐  │

 │ │ 3 Hexagons            │      │ Hexagon         │  │
 │ │ 3 Squares             │      │ Square          │  │
 │ │ 3 Triangles           │      │ Triangle        │  │
 │ └───────────┬───────────┘      └────────┬────────┘  │
 │             │                           │           │
 └─────────────┼───────────────────────────┼───────────┘
               │                           │
               └─────────────┬─────────────┘
                             ▼
                   ┌───────────────────┐
                   │  MODEL TRAINING   │
                   └─────────┬─────────┘
                             ▼
                   ┌─────────┴─────────┐             ┌─ TESTING DATA ─┐
                   │                   │             │                │
                   │    PREDICTION     │◄────────────┤ TEST DATA:     │
                   │                   │             │ Square         │
                   └─────────┬─────────┘             │ Triangle       │
                             │                       └────────────────┘
                             ▼
                   ┌───────────────────┐
                   │  PREDICTED OUTPUT │
                   │  Square           │
                   │  Triangle         │
                   └───────────────────┘
```

**How to read the diagram (follow the arrows):**

| Step | What Happens |
| :-- | :-- |
| **(1)** | **Labeled Data** (the shapes) and **Labels** (their correct names) **both** go into **Model Training** |
| **(2)** | **Model Training** produces a trained model that is used for **Prediction** |
| **(3)** | **Test Data** (a Square and a Triangle) is fed into **Prediction** from a separate path, because it is **not** part of the training data |
| **(4)** | **Prediction** outputs the label for each test item: **Square** and **Triangle** |

### 6.4 Colour Legend Used in the Original Slide

| Colour | Meaning | Includes |
| :-- | :-- | :-- |
| **Yellow** | **Training Data** | Labeled Data + Labels, used to **teach** the model |
| **Orange** | **Testing Data** | Test Data, used to **check** the model |

> **Why keep them separate?** If we tested the model on the same data it trained on, it could just **memorize** the answers. Testing on **unseen data** shows whether it has truly learned the pattern. This is the same idea as the **Evaluation** step in the 5-step ML pipeline from the previous note.

## 7. Summary

| Concept | One-Line Summary |
| :-- | :-- |
| **Supervised Learning** | Learning from **labeled data** (inputs + correct answers) |
| **Regression** | Predicts a **continuous number** (price, temperature, revenue) |
| **Classification** | Predicts a **discrete label** (Spam / Not Spam, Cat / Dog / Other) |
| **Features (`X`)** | The **inputs** given to the model |
| **Target (`y`)** | The **answer** the model must predict |
| **Training Data** | Labeled examples that **teach** the model |
| **Testing Data** | Unseen examples that **check** the model |
